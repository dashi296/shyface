# shyface

## E2E テスト用フィクスチャのセットアップ

```bash
bun run e2e:setup
```

> **注意**: `e2e:setup` は対象シミュレーターのフォトライブラリを**全消去**してからフィクスチャを注入します。
> 必ず **e2e テスト専用のシミュレーター**で実行してください。個人の写真が入ったシミュレーターで実行すると写真が失われます。

### コマンド一覧

| コマンド | 説明 |
|---|---|
| `bun run e2e:setup` | フィクスチャ生成 + シミュレーターへの注入（フォトライブラリを全消去してから注入） |
| `bun run e2e:download` | フィクスチャ画像の生成のみ（シミュレーターへの注入は行わない） |
| `bun run e2e:load` | 生成済みフィクスチャをシミュレーターへ注入（フォトライブラリは消去しない） |

### 前提条件

- Docker がインストール・起動済みであること
- e2e テスト専用の iOS シミュレーターが起動済みであること
- 初回実行時のみインターネット接続が必要（InsightFace モデル約 350MB をダウンロード）
